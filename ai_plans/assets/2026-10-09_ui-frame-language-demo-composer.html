Tumble Code: frames, toolbar chips and history rows

Left column: what main renders today. Right column: the proposal. Top row is the dark theme (VS Code "Dark Modern"), bottom row is the light theme ("Light Modern"). Hover the rows and chips, click into the composer and press Tab to see the focus ring.

What changes and why

  1. One dimmer frame colour for everything. History rows, the composer, the mode/model/auto-approve chips and the memory/index icons all use the same border: 13% of the theme foreground instead of 25% (rows, composer) or hard-coded rgba(255,255,255,0.08) (chips). Hover raises it to 26%, keyboard focus uses the theme focus colour.
  2. Light theme fix. The chips' white-at-8% border is invisible on a white background, so in light themes the mode and model selectors had no frame at all. Mixing from the theme foreground works in both.
  3. Rows read as cards, not as a table. A 3% tinted fill, 8px gap between cards (was 4px), even 10/12px padding, the title in full foreground with weight 500 and the meta line in the normal description colour (it was description colour at 60%, below comfortable contrast).
  4. Subtasks toggle sits under a hairline inside the card and is a full-width hover target.
  5. Same size for every toolbar control: 22px high chips and 22x22 icon buttons, so the memory and index icons line up with the selectors. A busy memory icon also tints its frame green.
  6. Hover and focus states on every card and chip (today the rows only change text opacity).
  7. Tool blocks in the chat get the same frame plus the existing 2px status edge.
