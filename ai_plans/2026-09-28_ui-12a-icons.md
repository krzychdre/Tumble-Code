# UI §2.12 part a: lucide plus codicons only (2026-09-28)

Source: `ai_plans/2026-09-27_ui-modernization.md` §2.12 ("lucide plus codicons only, drop
`@radix-ui/react-icons` and `react-icons`") and roadmap item D12 in
`ai_plans/2026-09-27_simplification-roadmap.md`. First branch of the §2.12 stack
(`refactor/ui-12a-icons` -> `refactor/ui-12b-no-styled-components` -> `refactor/ui-12c-primitives`).

## Inventory (verified with `git grep` on main 19d6d7dc7)

Only `webview-ui` used the two packages; `apps/`, `packages/` and `src/` had no imports.

| File                                  | Old glyph                                      | New glyph                                    |
| ------------------------------------- | ---------------------------------------------- | -------------------------------------------- |
| `ui/command.tsx`                      | radix `MagnifyingGlassIcon`                    | lucide `Search` (same classes)               |
| `ui/dropdown-menu.tsx`                | radix `CheckIcon`, `DotFilledIcon`             | lucide `Check`, `Circle` with `fill-current` |
| `chat/checkpoints/CheckpointMenu.tsx` | radix `CheckIcon`, `Cross2Icon` (15px default) | lucide `Check`, `X` with `size-4`            |
| `settings/ApiOptions.tsx`             | radix `ExternalLinkIcon`                       | lucide `ExternalLink`                        |
| `chat/Announcement.tsx`               | react-icons `SiX`, `SiDiscord`, `SiReddit`     | inline SVGs in `chat/BrandIcons.tsx`         |

## Decisions

- Brand logos: lucide removed its brand icons and codicons have no X, Discord or Reddit glyph, so the
  three Simple Icons paths (CC0, the same data react-icons shipped) are inlined in `BrandIcons.tsx`.
  This keeps the logos recognisable without keeping an icon library for three glyphs.
- Radix glyphs rendered at 15px when no class was given (checkpoint menu); lucide gets `size-4` (16px),
  the nearest step on the Tailwind scale, instead of an arbitrary `[15px]` value.

## Tests

Characterization first (commit 1, green on main): `ui/__tests__/icons.call-sites.spec.tsx` (command
glyph position and classes, dropdown checkbox and radio indicator painted only when checked),
`Announcement.spec.tsx` (each social link has one aria-hidden svg and a screen-reader label),
`CheckpointSaved.spec.tsx` (confirm and cancel show one glyph before the label). The move (commit 2)
keeps them green unchanged.
