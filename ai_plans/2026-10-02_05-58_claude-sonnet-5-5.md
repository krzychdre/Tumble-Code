## Problem

No table offered Claude Sonnet 5.5, although the LiteLLM default (`lite-llm.ts:4`, set by #674) already names it.

## Fix

- `claudeModels["sonnet-5-5"]`: 128K output, 1M context, $2 / $10, cache writes $2.50, reads $0.20, the same
  capability flags as Sonnet 5 (`supportsReasoningBudget`, `supportsReasoningBinary`, `supportsTemperature: false`),
  images and prompt caching, a description. Spread into Anthropic (`claude-sonnet-5-5`), Vertex (`claude-sonnet-5-5`)
  and Bedrock (`anthropic.claude-sonnet-5-5`, with the Bedrock cache points, plus the global inference list), each
  placed before Sonnet 5.
- OpenRouter: `anthropic/claude-sonnet-5.5` added to `OPEN_ROUTER_PROMPT_CACHING_MODELS`,
  `OPEN_ROUTER_REASONING_BUDGET_MODELS` and the fetcher's Claude 5 map (binary toggle, no temperature, max output
  from the Anthropic table), like Opus 5.5.
- LiteLLM: unchanged. `litellmDefaultModelId` now names a model the Anthropic table offers.
  `litellmDefaultModelInfo` stays the conservative fallback (200K, 8192, $3 / $15): it is used for any model id the
  proxy reports no info for (`provider-model-selection.ts:271`), not only for the default id.

### Disabled thinking

No request path sends `{type: "disabled"}` or a budget to a model with Sonnet 5's flags:

- Anthropic and Vertex: `getAnthropicProviderReasoning` (`src/api/transform/reasoning.ts:70`) sends
  `{type: "adaptive"}` when the toggle is on and nothing otherwise; the budget branch is never reached with the
  toggle on, and with it off `shouldUseReasoningBudget` is false. An omitted parameter runs adaptive thinking on
  Sonnet 5.5, so turning the toggle off does not turn thinking off (same as Opus 5.5; there is no "off" for these
  models in the UI). `between_tools` is not used.
- Bedrock: `buildThinkingFields` (`src/api/providers/bedrock/request.ts:203`) sends adaptive thinking for ids that
  `isAdaptiveThinkingModel` matches (`sonnet-5` also matches `sonnet-5-5`) and nothing when off.
- The only `type: "disabled"` senders are the DeepSeek, Z.ai and OpenAI-compatible GLM paths.
- Temperature is dropped by `supportsTemperature: false` (`model-params.ts:148`) and by the Bedrock adaptive guard.
- Forced tool choice: the task loop sends `tool_choice: "auto"`.

## Notes / caveats

- Not tested against the live APIs. The Bedrock handler uses the Converse API with the `anthropic.` id; the docs'
  Bedrock page describes the Messages (Mantle) endpoint with the same id format.
- Sonnet 5.5 default effort is `high`; Bedrock sends `xhigh` for every adaptive model, as before.
- OpenRouter: the toggle sends `reasoning.max_tokens` (budget) as for Sonnet 5 and Opus 5.5; OpenRouter translates it
  for the adaptive models. Unchanged behaviour, not verified live for Sonnet 5.5.
- The webview default models and the CLI model lists were not changed (Opus 5 / 5.5 stay the defaults).
