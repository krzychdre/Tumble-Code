# CLI: model size per model

Status: done on `feat/cli-model-size` (local only, stacked on `feat/compact-small-model-profile`, not merged). Overview
of the compact profile: `2026-10-10_19-36_compact-small-model-profile.md`.

## Goal

The VS Code profile settings pick "Model size" (standard, slim toolset, compact mode). The CLI has no provider
profiles; the owner wants the same choice in the model's entry of `cli-settings.json`, next to `contextWindow`.

## Shape

```json
{ "models": { "Qwen3.8-4B": { "contextWindow": 32768, "modelSize": "compact" } } }
```

- `modelSize`: `"standard" | "slim" | "compact"` (`MODEL_SIZES` in `apps/cli/src/types/constants.ts`), default
  standard. `hideMcp`: boolean, only read with `"slim"`, default true (the slim default of `slimHidesMcp`).
- `applyModelSettings` (`apps/cli/src/lib/utils/provider-config.ts`) writes, for every provider and always:
  `slimToolset = modelSize === "slim"`, `slimHidesMcp = hideMcp !== false`, `compactProfile = modelSize ===
"compact"`. Always, because the startup settings merge key by key into the persisted extension state, so an absent
  key would keep a compact flag from an earlier run or model (same reason as `openAiPreserveReasoning`).
- Every compact behaviour already reads `isCompactProfile(task.apiConfiguration)`, and the CLI's settings reach the
  task whole: initial settings, `cliModeProviderSettings` per mode (`ModeProfileBinding.resolve`) and `/model`
  (`withModel` -> `applyCliProviderSettingsToCurrentMode` -> `task.updateApiConfiguration`). No core change.
- Validation (`findModelSettingsProblems`): an unknown `modelSize` and a non-boolean `hideMcp` fail at startup with
  the model named. `listSetModelSettings` skips `modelSize` and `hideMcp` (every provider takes them), so no
  "ignored with the X provider" warning.
- `/model` lists `slim` / `compact` next to the size.

## Tests

- `provider-config.test.ts`: compact with a non-openai provider, slim with and without `hideMcp`, stale flags
  cleared, `withModel` brings and drops the new model's size; exact-shape expectations gained the three flags.
- `model-settings.test.ts`: the three sizes accepted, another value rejected, `hideMcp` boolean check, no ignored
  warning keys.
- `model-command.test.ts`: the `/model` list names slim/compact and leaves standard out.
