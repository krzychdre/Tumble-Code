## Problem

The service's lock file was behind on minor and patch releases (FastAPI 0.141.1, Starlette 1.7, Pydantic 2.13.5,
uvicorn 0.53, asyncpg 0.31, websockets 17.1 and others), the base image was python:3.13.15-slim and uv was 0.12.18.

## Change

- `uv lock --upgrade`, then `uv lock --upgrade-package sqlalchemy==2.0.54` so SQLAlchemy stays on 2.0.x. The 2.1
  migration is its own item. Notable moves: fastapi 0.161.1, starlette 1.9.0, pydantic 2.14.1, pydantic-settings
  2.16.1, uvicorn 0.54.0, uvloop 0.23.0, asyncpg 0.32.0, alembic 1.20.1, pyjwt 2.15.1, cryptography 50.0.2,
  websockets 17.3, certifi 2026.10.23. `deprecated` moves to 3.0.0 (a dependency of `limits`, used by slowapi) and
  pulls in `opentelemetry-api`.
- Dockerfile: `python:3.13.17-slim@sha256:fe14fd57...` and `ghcr.io/astral-sh/uv:0.13.5@sha256:32a7bb39...`,
  digests read with `docker buildx imagetools inspect`.

## Tests

- Full `uv run pytest -q`: 1345 passed, 1 xfailed.
- `docker build` with a throwaway tag: the image builds, reports Python 3.13.17, uv 0.13.5, SQLAlchemy 2.0.54,
  FastAPI 0.161.1. The throwaway image was deleted.

## Notes

The live api image is not rebuilt by this change; the owner rebuilds it.
