# Cloud web panel: math formulas in task conversations

Status: done on `feat/cloud-web-math`

## Problem

The owner asked (2026-10-12) for math notation in the self-hosted cloud web panel, after the extension
(#867, #868) and the CLI (#869) got it. The task page renders Markdown with `marked` + `DOMPurify`
(`static/render.js`, `md()`) and knew no math: TeX reached the page raw, and marked ate its `_`, `*`
and `\` (an `x_1 * x_2` turned into italics).

## Design

- **KaTeX 0.18.9 vendored** under `static/vendor/katex/` (min JS, min CSS, the 20 woff2 fonts, the MIT
  license); same version as webview-ui. Self-hosted because the panel's CSP allows `script-src`,
  `style-src` and `font-src` `'self'` only. KaTeX's computed `style="..."` attributes fit the existing
  `style-src-attr 'unsafe-inline'`. Loaded only by `task_detail.html` (new `{% block head %}` in
  `base.html` for its stylesheet), with `?v=` like every other asset.
- **Delimiters as in the extension and the CLI**: `$$...$$` and `\[...\]` are display math when they
  fill their lines, inline otherwise; `\(...\)` and `$...$` are inline. `$...$` follows Pandoc's rule
  (no space just inside the dollars, no digit after the closing one) and may not contain a backtick, so
  `$5 and $10` and a `` `$x$` `` code span stay text. Bracket forms need TeX inside (`\[1\]` is an
  escaped `[1]`). Fenced blocks and code spans are skipped.
- **Placeholders**: `extractMath` swaps each formula for `TUMBLEMATH<n>X` before `marked.parse`, then
  the placeholders are replaced by `katex.renderToString` output and the whole result goes through
  `DOMPurify.sanitize` as before. marked never sees the TeX, and a `|` in a formula no longer splits a
  table cell.
- KaTeX options: `throwOnError: false` (a bad formula shows red source, the row still renders),
  `strict: "ignore"`, `trust` left off (`\href`, `\htmlClass` are refused). Without KaTeX loaded the
  text passes through unchanged.

## Tests

`tests/browser/math_checks.html` (run by `test_browser_js.py`, min 12 checks): inline and display,
`\boldsymbol{\tau}`, MathML surviving DOMPurify, `_`/`*` inside a formula, dollar amounts, escaped
brackets, code spans and fences, a formula in a table cell, `$$` inside a sentence, `\href` with
`javascript:`, an unclosed `\frac`. Full cloudapi suite: 1322 passed.
