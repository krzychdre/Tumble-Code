## Problem

`detectAgentState` spelled the same nine-field object seven times (plus an "impossible" `!lastMessage` copy).
`description` (`getStateDescription`), `requiredAction` (`RequiredAction`, `getRequiredAction`) and
`lastMessageTs` (a copy of `lastMessage.ts`) were read only by one debug log or by tests.

## Change

- `AgentStateInfo` keeps `state`, the three flags, `currentAsk` and `lastMessage`.
- `make(state, lastMessage?, currentAsk?)` builds every result; the three flags follow from the state (the old
  literals agreed with that rule in every branch).
- `messages.at(-1)` replaces the length check and the impossible guard; the `undefined` messages spec goes with it
  (the only caller passes the deliveries' transcript array).
