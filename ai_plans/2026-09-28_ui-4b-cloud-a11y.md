# UI-4b: cloud web panel accessibility and a Content Security Policy

Plan: `ai_plans/2026-09-27_ui-modernization.md`, section 3.5 (step 4 of section 5).
Branch: `feat/ui-4b-cloud-a11y`, stacked on `feat/ui-4a-cloud-list`. Everything is in
`self-hosted-cloudapi/`.

## What

- **Skip link** as the first element of `base.html` ("Skip to content", off screen until
  focused) and `<main id="main" tabindex="-1">`, so the link moves focus, not only the
  scroll.
- **Contrast**: `--text-faint` from `#6b7885` (4.2:1 on `--bg`, 3.9:1 on `--surface-1`) to
  `#7d8a97` (5.4:1 and 5.0:1). Pinned by a test that computes the WCAG ratio from the
  tokens.
- **Type scale**: every `font-size` in `app.css` is now a `var(--t-*)`. The one-offs were
  folded: `0.9375rem` and `0.95rem` to `--t-body`, `1.125rem` to `--t-lead`, the `0.8rem`
  carets to `--t-micro`, and two new tokens for what had no equivalent: `--t-tick`
  (0.625rem, the conversation fold caret, was 0.6rem) and `--t-inline` (0.9em, units and
  inline code). `--t-h1: clamp(1.25rem, 1rem + 1vw, 1.5rem)` sets every page title, which
  replaces the 640px override.
- **Tables**: `<caption>` (visually hidden) on the spend table and the three metrics
  breakdowns, `scope="col"` on every header cell.
- **Announcements**: the live status line is `role="status" aria-live="polite"`; the task
  list has a persistent `#list-status` live region outside the swapped results, and
  `tasklist.js` writes the new count there after a filter swap ("3 tasks").
- **Emoji**: the folder emoji before the workspace path is `aria-hidden`.
- **No inline behaviour**: the two inline `onsubmit` confirms (task delete, retention
  "Run now") became `data-confirm` on the form, handled by a new shared `static/app.js`
  loaded with `defer` from `base.html`. The two inline `style="display:none"` (live
  activity, Stop button) became the `hidden` attribute and `live.js` toggles `.hidden`; a
  global `[hidden] { display: none !important }` keeps `.btn` (inline-flex) from
  overriding it. The task list's `<noscript><style>` became a `noscript.css` link.
- **Content Security Policy** on `/app` and `/shared` HTML responses (a pure ASGI
  middleware, `src/middleware/content_security_policy.py`, outermost so the 403 page
  carries it too):
  `default-src 'self'; script-src 'self'; style-src 'self'; style-src-attr 'unsafe-inline';
  img-src 'self' data: https:; font-src 'self'; object-src 'none'; base-uri 'self';
  form-action 'self'; frame-ancestors 'none'; connect-src 'self' ws://host wss://host`.
- **Empty state**: a user with no tasks gets a "connect the extension" panel: set
  `tumble-code.cloudApiUrl` to the API URL (shown in a `<code>` with a Copy button that
  `app.js` reveals), sign in, click Share. The filtered empty state came with 4a.

## Why these choices

- `style-src-attr 'unsafe-inline'`: a handful of computed `style` attributes remain
  (`--depth` for the tree indent, the grade bar and kind bar widths). An attribute cannot
  load a resource or run code; a `<style>` element can exfiltrate attribute values with
  selectors, and stays refused. 5d replaces the bars' widths with SVG geometry.
- `img-src https:`: a model's Markdown can embed a remote image; blocking it would change
  what a conversation shows. Attachments are `data:` URLs.
- ws/wss origins are spelled out from the request's `Host` (validated against a strict
  pattern) because older browsers do not let `'self'` cover websockets.
- The sign-in pages (`/auth/...`, `routers/browser.py`) keep their inline script (they hand
  the browser back to VS Code) and get no policy; JSON gets none either.

## Verification beyond the tests

A local server (SQLite, seeded, a fixed web user) and headless Chrome with console logging
on: `/app`, a task page, `/app/metrics`, `/app/settings`, `/shared/<id>` and a 404 log no
console message at all (no CSP violation); Chart.js still draws its three canvases and the
conversation renders; the socket.io client reaches the bridge handshake.

## Deviations

- The plan listed "seven one-off font sizes"; there were eight declarations (two of them
  relative `0.9em`). Two tokens were added rather than rounding the fold caret and inline
  code to an existing step.
- The metrics empty state only lost an em dash; the connect panel sits on the task list,
  which is where a new user lands.

## Tests

- `tests/test_web_a11y_csp.py` (21): skip link and main on every page, contrast from the
  tokens, type scale, captions and scopes, live status, emoji, count announcement region,
  templates without handlers/`display:none`/`<style>`, rendered pages without inline
  script (JSON islands only), data-confirm forms and `app.js`, hidden attributes, the CSP
  directives, no CSP on `/health` and `/auth/error`, the connect empty state.
- Browser harnesses: new `app_checks.html` (7: confirm decline/accept, forms without
  `data-confirm`, copy button revealed and copying); `live_checks.html` now checks the
  `hidden` attribute; `tasklist_filter_checks.html` checks the count announcement.
