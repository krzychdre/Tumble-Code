# r4: Prettier 3.5.3 to 3.9.10 with the whole-tree reformat

**Status:** done on `chore/r4-prettier-3-latest`.

**Related plans:** `ai_plans/2026-10-23_17-20_maintenance-audit-round-4.md` (the minor-version group deferred the
reformat to its own change).

## Touched files

- `package.json` (`prettier` `^3.9.10`), `pnpm-lock.yaml`, `.prettierignore`.
- 153 files reformatted: every tracked `*.{js,jsx,ts,tsx,json,css,md}` file (the lint-staged pattern) that
  `prettier --list-different` reported. Some were already off under 3.5.3 (104 files, committed past the hook).

## Change

Formatting only, so the merge commit goes into `.git-blame-ignore-revs`.

## Tests

- Code (100 files): the TypeScript AST of each file before and after, printed without comments and with
  whitespace outside string literals and trailing commas dropped, plus the list of comment texts, is identical
  for all `.ts`, `.js` and `.json` files. For `.tsx`, the same comparison with JSX text removed, plus the
  `react-jsx` transpile output, is identical except for three files whose only change is dropped grouping
  parentheses or whitespace inside a template literal's `${}` (checked by hand).
- Markdown (53 files): the rendered HTML (marked, GFM) is identical except for whitespace and reformatted example
  code inside fenced blocks. Three files whose rendering Prettier 3.9 changed (escapes in pasted logs, a verbatim
  quote of React Compiler output) are left as they were and listed in `.prettierignore`.
- The reformatted specs in `src` (8 files) and `webview-ui` (4 files) pass; `pnpm knip` exits 0.

## Notes

- `.prettierrc.json` carries an `ignore` key that Prettier does not know (it prints "Ignored unknown option");
  `.prettierignore` and `.gitignore` already cover those paths.
