## Change

- **`CSI E` rewrite deleted.** Ink 7 skipped an unchanged row with Cursor Next Line even when that row was new
  (a blank row matching the trailing empty entry of the previous frame), which does not scroll on the bottom
  row and left ghost footers. Ink 8 (#1039) writes new rows with a line feed and uses `CSI E` only over rows the
  previous frame already occupied. The wrapper keeps only the image-marker expansion, hence the new name.
- **`TailViewport` uses `<Box maxHeight>`.** Ink applies style props while it reconciles, before its layout, so
  the cap holds from the first frame. The insertion effect, the layout effect and the forced second render that
  set the yoga max-height by hand are gone; the mount spec now asserts exactly one, already clipped, frame.
- **React build probes count `performance.measure` calls.** react-reconciler 0.34 clears each measure right
  after recording it, so the old probe (retained entries) read 0 for both builds and could no longer tell them
  apart. The development reconciler still measures every commit with a JSON diff of the changed props, so
  `loadReactProductionBuilds` stays.
