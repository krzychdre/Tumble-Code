A recording holds the full system prompt, the tool definitions, the whole conversation as sent (with every file, command output and path in it), the exact HTTP body the provider received (never its headers or API key), the model's answer and how each tool call went. It stays on this server until you delete it or the task.

Matched as whole words in any case and with any separator ("QUB-IT" also finds "qub_it"), and replaced with a pseudonym such as acme1. Your account's name and e-mail are always anonymized.
