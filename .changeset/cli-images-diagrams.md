New: **CLI: images and diagrams.** In terminals that draw images (kitty, Ghostty, WezTerm, iTerm2, foot, xterm, the VS Code terminal) the CLI shows the images an answer points to, and it draws mermaid diagrams everywhere, with box-drawing characters where images are not available. `TUMBLE_IMAGES=off` turns images off.
