The chat input and everything around it now share one frame style. The composer, the mode, model, auto-approve and worktree buttons under it, and the memory and code-index icons all use the same thin border that brightens on hover and shows the theme focus ring when you move to them with the keyboard, so they line up at the same 22px height and stay visible in light themes. The menus they open (modes, API configurations, auto-approve, worktrees, code index and the @ mention list) use the same dividers, inset rows with a soft hover, a tinted selected row with a check mark, a shadow taken from the theme, and readable secondary text instead of faded text. Auto-approve options are now outlined tiles that show a check when on and an orange frame when a mode forces them, the pin button in the API configuration list is always visible, and the code-index workspace checkboxes use the same checkbox as the rest of the extension.
