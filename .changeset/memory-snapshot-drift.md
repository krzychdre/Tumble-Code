Memory: the dream now checks what each note names against the repository as it was on the note's last-change day. Files that moved or were removed, code names that left the code and stated package versions that changed since are listed in one line at the top of the note, with the commit date and PR (for example "`StyledPre` is no longer in the code (removed 2026-09-28, #611)"). No keywords and no model are involved, so it works for notes in any language. Memory files are now written in English.
