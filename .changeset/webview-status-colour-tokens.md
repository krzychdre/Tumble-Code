Status dots, success and error messages, validation borders and similar accents in the chat, the code index settings and the marketplace now take their colours from the VS Code theme instead of fixed Tailwind colours, so they stay readable in light and high contrast themes. Running commands, MCP calls and code indexing now show the same "running" colour as tool blocks (the theme's link colour, previously yellow or green).
