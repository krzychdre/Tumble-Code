You can now work in several Tumble Code editor tabs at once. A Tumble tab's title bar has an "Open In New Tab" button, and Alt+click on the Tumble button of a file editor opens a fresh tab instead of showing the open one; a new tab opens next to the Tumble tab you used last. With several tabs open, the Tumble button, the status bar entry and the focus commands go to the tab you used last, closing one tab no longer makes them lose the others, and clicking inside one tab no longer jumps to another tab. Opening a task from the history that another Tumble panel is running shows it in that panel instead of starting it a second time. After "Restart Extensions", every Tumble tab the old extension host left behind is replaced, not only the first.
