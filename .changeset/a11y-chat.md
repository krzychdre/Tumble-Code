The chat can now be used with the keyboard in three more places: the header of an MCP tool call is a real button that Tab reaches and Enter or Space expands, each file row of a batch file-read request can be focused and opened with Enter or Space, and the checkpoint menu (view diff, restore, jump to previous, more) appears when keyboard focus enters the checkpoint row instead of only on mouse hover. Mouse behaviour is unchanged.
