The chat transcript now uses the same calm frame everywhere: the task header is a closed card, your own messages are a tinted card with a blue edge instead of an inverted block, and every tool block (file reads, commands, MCP calls, diffs, skills) has the same thin frame, a status edge and a clear header row. Errors and warnings appear as tinted cards, checkpoints use a thin theme-blue line, and the to-do list sits in its own card. Buttons that used to appear only on hover (copy, docs, edit and delete on your messages, the thinking chevron, image remove buttons) are now always visible, and command status dots always come with a word or the exit code.
