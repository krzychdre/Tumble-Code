A task keeps working when you open another task, its subtask or parent, or go back to the home screen. Before, leaving a task stopped it. A task that is still working stays alive in the background; opening it again shows it where it is, including an approval or a question it is waiting for. A task that has finished, failed or waits to be resumed is closed as before. The CLI still stops the task it leaves.
