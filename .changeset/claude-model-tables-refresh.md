Retired Claude models (Claude 3, 3.5, 3.7 and Opus 4.1) are no longer offered for Anthropic, Vertex AI, Amazon Bedrock and OpenRouter, and the LiteLLM default model is now Claude Sonnet 5.5. On Vertex AI and Bedrock, Claude Opus 4.6 and newer, Sonnet 5 and Fable models now allow up to 128K output tokens in the settings, the same as on the Anthropic API.
