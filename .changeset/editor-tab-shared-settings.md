Switches in Tumble Code now stay in step when it is open in an editor tab and in the sidebar at the same time. A setting changed in one view (or from the web cockpit, or a cloud sign-in) used to refresh only that view, so the other kept the old value and its next click flipped the setting back. The codebase indexing popover also no longer throws away an unsaved edit, such as the unticked "Enable" box, while a task is running.
