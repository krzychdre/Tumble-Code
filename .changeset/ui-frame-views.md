The MCP servers list, the Marketplace, the Cloud page, the Worktrees page, the plan review screen and the image and diagram zoom window now use the same framed cards, hover colours and keyboard focus ring as the rest of the extension. Each MCP server shows its state as a word (Running, Connecting, Disconnected, Disabled) next to the coloured dot, MCP servers and worktrees can be opened with the keyboard, and the image toolbar (zoom, copy, save) stays visible instead of appearing only under the mouse.
