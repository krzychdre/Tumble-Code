Text fields across the webview now use one component with VS Code's field look. Fields in the history search, mode editor, code index setup, cloud sign-in, marketplace and worktree dialogs share the same height, border and focus colour. The mode prompt fields still save when you leave them, and a callback URL pasted on the cloud sign-in page is sent at once while a typed one is sent with Enter.
